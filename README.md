## 🌿 Sobre o projeto

O **ARBO** é um Projeto Integrador desenvolvido no curso de **Análise e Desenvolvimento de Sistemas da FATEC Ferraz de Vasconcelos**, na disciplina de Programação Web.

A preservação das áreas verdes urbanas exige a colaboração entre cidadãos, organizações ambientais e órgãos públicos. Entretanto, a falta de canais acessíveis para comunicar problemas ambientais e acompanhar sua resolução pode dificultar a participação da comunidade.

Pensando nisso, nasceu o **ARBO**, uma plataforma web que conecta pessoas e instituições para promover uma gestão ambiental mais colaborativa, acessível e organizada, com foco no município de **Ferraz de Vasconcelos (SP)**.

A proposta é transformar o registro de problemas ambientais em oportunidades de mobilização, conscientização e recuperação dos espaços urbanos.

---

## 🎯 Problema e solução

### 🔴 O problema

Problemas como descarte irregular de resíduos, focos de dengue e degradação de áreas verdes podem comprometer a qualidade de vida da população.

A ausência de integração entre cidadãos e instituições dificulta a comunicação das ocorrências, o acompanhamento das demandas e a organização de iniciativas coletivas.

### 🟢 Nossa solução

O ARBO oferece um ambiente digital que permite:

- 📍 Registrar ocorrências ambientais com localização.
- 📷 Adicionar descrições e fotografias.
- 🔎 Consultar e acompanhar ocorrências.
- 🏛️ Facilitar a atuação de ONGs e órgãos públicos.
- 🌳 Divulgar e organizar mutirões ambientais.
- 🤝 Incentivar a participação dos cidadãos em ações de preservação.

---

## ✨ Funcionalidades

### 👤 Cidadãos

- Registro de ocorrências ambientais.
- Inclusão de descrições, imagens e localização.
- Consulta e acompanhamento dos registros.
- Visualização de mutirões disponíveis.
- Inscrição em mutirões ambientais.

### 🏛️ ONGs e órgãos públicos

- Consulta das ocorrências cadastradas.
- Análise e atualização dos registros.
- Aprovação ou recusa de ocorrências.
- Marcação de ocorrências resolvidas.
- Organização e divulgação de mutirões.

## 🏗️ Arquitetura do projeto

O back-end segue uma arquitetura em camadas, separando responsabilidades para facilitar a manutenção e a evolução do sistema.

    backend/arbo-backend/src/main/java/com/arbo/arbo/backend/
    ├── controller/    # Endpoints HTTP da API
    ├── service/       # Regras de negócio
    ├── repository/    # Acesso ao banco de dados
    └── model/         # Entidades do sistema

### Responsabilidades

| Camada | Descrição |
|---|---|
| Controller | Recebe e responde às requisições HTTP |
| Service | Implementa as regras de negócio |
| Repository | Gerencia a persistência dos dados |
| Model | Representa as entidades do sistema |

## 🚀 Como executar o projeto localmente

### 📋 Pré-requisitos

Para executar o ARBO, é necessário ter:

- Git
- Java JDK 21
- Node.js e npm
- Maven ou Maven Wrapper
- MySQL, caso utilize a configuração com banco persistente

### 1. Clonar o repositório

    git clone https://github.com/Arbo-Plataforma-Ambiental/Arbo.git
    cd Arbo

### 2. Executar o back-end

Entre na pasta:

    cd backend/arbo-backend

**Windows (PowerShell):**

    .\mvnw.cmd spring-boot:run

**Linux/macOS:**

    ./mvnw spring-boot:run

Ou, com Maven instalado:

    mvn spring-boot:run

A API ficará disponível em:

http://localhost:8080

### 🗄️ Configuração do banco de dados

O projeto possui suporte ao MySQL e utiliza o H2 em memória na configuração atual de desenvolvimento.

Para utilizar o H2, mantenha as configurações correspondentes no arquivo:

`backend/arbo-backend/src/main/resources/application.properties`

Para utilizar o MySQL, configure a conexão no mesmo arquivo e, quando necessário, execute o script SQL do projeto.

Não publique credenciais de banco de dados no repositório.

### 3. Executar o front-end

Abra outro terminal na raiz do repositório:

    cd frontend
    npm install
    npm run dev

O Vite exibirá o endereço local da aplicação, geralmente:

http://localhost:5173

Mantenha o back-end em execução para utilizar as funcionalidades que dependem da API.

## 📈 Monitoramento da aplicação

O ARBO utiliza Spring Boot Actuator e Micrometer para disponibilizar métricas operacionais do back-end.

Com a aplicação em execução, os endpoints de monitoramento podem ser acessados em:

| Endpoint | Finalidade |
|---|---|
| `/actuator/health` | Verificar a saúde da aplicação |
| `/actuator/prometheus` | Exportar métricas no formato Prometheus |

A integração com o servidor Prometheus está em desenvolvimento, com o objetivo de acompanhar indicadores como:

- Consumo de memória da JVM.
- Utilização de CPU.
- Requisições HTTP.
- Tempo de resposta da API.
- Disponibilidade do back-end.

> Os endpoints de monitoramento devem ter seu acesso revisado antes da publicação em produção.
